# AIMS 使用手册（桌面版）

## 1. 启动与退出

- **启动**：双击桌面上的 **AIMS** 图标。首次启动会显示初始化进度（1–3 分钟），
  之后每次都很快（数据库已在后台运行）。
- **界面**：启动完成后自动弹出 AIMS 主界面（独立窗口，无地址栏）。
  如果窗口被关掉了，右键任务栏托盘里的 AIMS 图标 → **打开 AIMS 主界面**。
- **退出**：右键托盘图标 → **退出**。请用这种方式退出：
  它会先关闭后端、再停数据库，不会留下后台进程。
  直接在任务管理器里结束 AIMS 进程也能退出，但下次启动会稍慢（数据库需要恢复）。

> 关闭主界面窗口 ≠ 退出程序。AIMS 会继续在托盘运行，定时任务和报警照常工作。

## 2. 托盘菜单能做什么

| 菜单项 | 用途 |
|---|---|
| 打开 AIMS 主界面 | 重新打开窗口 |
| 立即备份数据库 | 马上做一次完整备份（不需要停程序） |
| 打开数据目录 | 打开 `C:\ProgramData\AIMS`（数据库、备份、日志都在这） |
| 打开日志目录 | 出问题时给技术支持看这里 |
| 生成诊断报告 | 一键自检，弹窗显示每一项结果，并保存报告文件 |
| 重启服务 | 界面卡住/配置改过之后用（会中断当前操作，数据不丢） |
| 开机自动启动 | 勾选后登录 Windows 就自动运行并最小化到托盘 |
| 退出 | 正常退出程序 |

## 3. 首次登录

- 用户名：`admin`
- 初始口令：`admin123`（全新安装的默认账号就是 `admin` / `admin123`；实施人员
  可在安装时自定义初始口令，自定义后以 `C:\ProgramData\AIMS\Config\first-login.txt` 为准）。

**第一次登录后请立刻修改口令**：系统设置 → 修改密码。
口令规则见登录页提示（长度、复杂度）。

忘记口令时，让管理员在安装目录执行：

```powershell
.\AIMS-Backend\AIMS-Backend.exe reset-password
```

## 4. 主要功能地图

| 模块 | 你能做什么 |
|---|---|
| 总览看板 | 设备总数/在线率、健康分、未确认报警、待办工单（未连后端时显示"—"并标注演示模式） |
| 设备管理 | 新增/编辑设备、测点（部件）配置、导入导出 Excel、通信测试 |
| 数据管理 | 查询历史测点、批量导入（Excel/CSV）、按时间/部件筛选、趋势对比 |
| 报警中心（1.0 新增页面） | 报警列表（按状态/等级筛选）、确认、解决、阈值规则查看；确认人由后端认证身份写入，不可伪造 |
| AI 中心 | 对话问答、故障诊断、SOP 生成、ROI 测算、知识库问答 |
| 知识库 | 上传手册/规程、切片向量化、语义检索、RAG 问答 |
| 资产管理 | 资产台账、折旧与 ROI、资产文档挂接 |
| 数据分析 | 上传数据集、多曲线趋势、统计与预测 |
| 系统设置 | 用户管理（启用/停用）、系统参数、审计日志、后台组件（版本/状态/许可证/路径/磁盘占用，真实采集） |

> 所有功能都在本机运行：数据不出内网，AI 推理用本地模型（未部署模型时自动降级为规则引擎，
> 界面上会明确标注"规则引擎"，不会假装是模型输出）。

### 4.1 故障 PDF 分析（维护 → PDF Import）

上传故障分析 PDF 后，系统会真实解析（pypdf 提取文本层），给出：页数/字符数、识别到的设备位号、
报警码、测量值与单位、命中故障关键词的原始行，并附上内置规则包给出的**候选诊断（仅供参考）**。

- 扫描件/纯图片 PDF 没有文本层：会明确提示"需要先 OCR"，不会编造结果；
- 含可执行动作（/JavaScript、/Launch）的 PDF 会被拒收；
- 解析结果不会自动写库或创建工单，需人工确认后走报警/工单流程。

## 5. 备份与恢复（用户视角）

- 程序**每次启动**会自动备份（12 小时内不重复），安装/升级前也会自动备份。
- 需要立刻备份：托盘菜单 → **立即备份数据库**。
- 备份文件在 `C:\ProgramData\AIMS\Backup`，文件名形如 `aims-20260101-030000.dump`。
- **恢复**需要先退出 AIMS，然后由管理员执行：

  ```powershell
  cd "C:\Program Files\AIMS\tools"
  .\restore.ps1                       # 恢复最新一份
  .\restore.ps1 -File aims-20260101-030000.dump
  ```

  恢复前会自动把当前数据再备份一份（`pre-restore-*.dump`），所以"恢复错了"还能再恢复回来。
- 建议定期把 `Backup` 目录复制到 U 盘或网络盘（异地保存）。

## 6. 数据放在哪里

| 内容 | 位置 |
|---|---|
| 业务数据库 | `C:\ProgramData\AIMS\Database` |
| 模型文件 | `C:\ProgramData\AIMS\Models` |
| 上传/导入导出文件 | `C:\ProgramData\AIMS\Uploads` |
| 配置（含口令） | `C:\ProgramData\AIMS\Config` |
| 日志 | `C:\ProgramData\AIMS\Logs` |
| 备份 | `C:\ProgramData\AIMS\Backup` |
| 程序本体 | `C:\Program Files\AIMS` |

升级程序**不会**动 `ProgramData` 下的任何数据；卸载程序默认也保留它。

## 7. 常见问题（用户版）

**双击图标没反应？**
等 10 秒。若仍无反应，看托盘有没有 AIMS 图标（可能在折叠区）；
仍不行则运行开始菜单 → AIMS → **AIMS 诊断报告**，把弹窗内容发给技术支持。

**界面提示"无法连接服务"？**
后端可能刚启动或已退出。托盘菜单 → **重启服务**。

**提示"端口 8000 被占用"？**
其它程序占用了端口。管理员可修改 `Config\aims.env` 的 `PORT` 后重启，或关闭占用程序。

**AI 问答回答得很"模板化"？**
说明当前没有部署本地大模型，正在用规则引擎。托盘 → 生成诊断报告，
看"AI 推理引擎"一项；需要模型时联系实施人员放置 GGUF 模型。

**换电脑/重装系统怎么办？**
拷贝整个 `C:\ProgramData\AIMS` 目录 + 最近的备份文件；新机器装好 AIMS 后，
停程序 → 用 `restore.ps1` 恢复备份 → 启动。配置和模型也一并带过去。
