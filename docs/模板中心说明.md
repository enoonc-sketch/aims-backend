# 模板中心使用说明（计划书第十二章）

> 模板中心让 AIMS 从"固定配置软件"变成**支持用户自主扩展、定制和共享模板的开放式平台**。
> 入口：主界面导航栏 **Templates · 模板中心**。

## 一、能做什么

| 能力 | 说明 |
|---|---|
| 内置官方模板 | 20 个分类、20 个官方模板（设备台账、气相色谱仪、报警配置、报表、AI 分析、RAG 知识库……），随软件自带，不可删除 |
| 创建/编辑/复制 | 「新建模板」用 JSON 定义模板正文；保存即生成新版本；「复制」可基于任何模板做自己的副本 |
| 导入 `.aimstpl` | 支持单包、多选、批量 ZIP（内含多个 .aimstpl）；**先预览后确认**，失败给出明确中文原因 |
| 导出 | 单个导出 `.aimstpl`；按 ID / 按分类 / 全部自定义模板批量导出 ZIP；U 盘拷贝即可迁移到其它电脑 |
| 应用模板 | 真正生成业务数据（见下表），不是"存个文件"；幂等：已存在的编码自动跳过，绝不覆盖现有数据 |
| 版本管理 | 每次修改追加版本，旧版本永不覆盖；版本比较（字段级 diff）、一键回退（回退本身也生成新版本） |
| 收藏/默认 | 收藏模板；可把某模板设为其分类的默认模板 |

## 二、应用模板 → 生成什么业务数据

| 模板分类 | 应用后创建 |
|---|---|
| 仪表管理 / 在线分析仪 / 气相色谱仪 / 设备台账 | 真实设备（Device）+ 测点组件（DeviceComponent） |
| TAG 点位 | 设备 TAG 点位（DeviceTag） |
| 通信配置 | 网关（Gateway） |
| 报警配置 | 基于目标设备测点上限生成阈值报警规则（AlarmRule） |
| 资产管理 | 资产台账（Asset） |
| 维护管理 | 维护 SOP（MaintenanceSOP） |
| RAG 知识库 | 知识文档 + 分块（KnowledgeDocument/Chunk，可被 RAG 检索） |
| 图表 / 工作流程 / 数据库查询 / AI 分析等 | **明确提示"暂不支持自动应用"**（不做假成功；内容仍可导出使用） |

## 三、.aimstpl 模板包格式

ZIP 容器，扩展名 `.aimstpl`：

```text
manifest.json    必需：uid/名称/分类/版本/最低兼容 AIMS 版本/作者/描述/依赖
template.json    必需：模板正文（devices / tags / alarm_rules / sops / report / chart …）
schema.json      可选：字段定义与校验规则
preview.png      可选：预览图
README.md        可选：使用说明
assets/**        可选：静态资源
scripts/**       可选：扩展脚本 —— 只随包存储，默认禁用，系统内无任何执行入口
```

## 四、安全机制（12.9）

1. **路径穿越检查**：包内 `../`、绝对路径、反斜杠一律拒绝。
2. **体积限制**：单包 64 MB、解压总量 256 MB 上限（防 zip 炸弹）、成员数 2000 上限。
3. **结构校验**：manifest/template.json 缺失、JSON 语法错误、必需字段缺失 → 拒绝并说明原因。
4. **版本兼容**：模板要求 AIMS ≥ x.y.z 而当前不满足 → 拒绝导入（不做半兼容状态）。
5. **脚本禁用**：scripts/ 永不执行，导入后 `scripts_enabled=false`。
6. **权限一致**：应用模板走与手工创建完全相同的业务通道和权限，不绕过任何安全限制。
7. **数据隔离**：删除模板只删模板与版本历史，已应用生成的设备/报警等业务数据不受影响。
8. **全程留痕**：导入（成功/失败）、应用、回退、导出都有日志，且写入系统审计日志。

## 五、常见问题

- **导入失败提示"JSON 解析失败（第 N 行）"** —— manifest.json/template.json 有语法错误，多为手工编辑时少了逗号/引号。
- **导入提示"已存在同 UID 模板"** —— 不是错误：确认导入后会追加为新版本，旧版本保留；不想追加就先删除旧模板或在导出端改 UID。
- **应用模板没有生成数据** —— 查看返回的"已存在跳过"信息：应用是幂等的新增，编码重复会跳过；报警模板还要求目标设备已有测点（组件），否则不建"永远不会触发的规则"。
- **如何迁移到另一台电脑** —— 「导出全部自定义模板」得到 ZIP → U 盘拷贝 → 对方机器「导入模板」选择该 ZIP。

## 六、数据库表

`template_registry`（注册表）、`template_versions`（版本历史）、`template_import_logs`（导入日志）、
`template_usage_logs`（使用记录）、`template_dependencies`（依赖关系）。
均为新增表，不触碰任何现有业务表；`AUTO_UPGRADE_SCHEMA` 会在升级时自动建表。
