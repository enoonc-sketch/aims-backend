# 依赖与许可证清单

本清单对应 **AIMS 1.0.0 Windows 离线安装版**。所有组件均随安装包分发，目标机不需要联网获取。

- 版本锁定文件：`requirements-exe.txt` / `requirements-exe.lock`
- 下载文件校验：`build\vendor.lock.json`（SHA-256，构建时强校验）
- 许可证全文：`LICENSES.txt`

## 2. 架构与平台矩阵

| 项 | x64 | ARM64 |
|---|---|---|
| 应用（EXE） | ✅ 原生 | ✅ 原生（需在 ARM64 构建机构建） |
| PostgreSQL | ✅ 原生 | ⚠️ 官方无原生版，走 Windows 11 x64 仿真（性能 -10~25%） |
| pgvector | ✅ 需预编译或本地编译 | ⚠️ 同上；或使用 `EMBEDDING_STORAGE=json` |
| llama.cpp | ✅ CPU | ⚠️ 依赖是否有 ARM64 轮子，否则降级规则引擎 |
| 验收状态 | 需在干净 Win11 x64 完成 `Windows-Acceptance.ps1` | 需在 Win11 ARM64 真机完成同样脚本 |

## 3. 许可证合规要点

1. **PostgreSQL / pgvector / pg_trgm**：类 BSD，分发时保留版权声明与许可文本即可（已在 `LICENSES.txt`）。
2. **psycopg2（LGPL-3.0）**：以动态库形式随包分发，未修改源码；提供 `LICENSES.txt` 中的许可证与获取源码的说明，符合 LGPL 要求。
3. **llama.cpp / llama-cpp-python（MIT）**：保留版权声明。
4. **模型权重**：Qwen2.5（Apache-2.0）、BGE（MIT）均允许商用；若替换为其它模型，需重新评估其许可。
5. **Inno Setup**：安装程序本身可自由分发，无需公开我们的脚本（但本项目脚本已随源码提供）。
6. **导出管制**：本项目使用的加密库（cryptography/OpenSSL）属常见公开组件，出口到受制裁地区前需自行评估。

## 4. 版本升级时需要更新的位置

| 内容 | 文件 |
|---|---|
| 产品版本号（唯一来源） | `app/deploy/__init__.py` → `APP_VERSION` |
| Python 依赖版本 | `requirements-exe.txt` + `requirements-exe.lock` |
| 内置 PostgreSQL 版本 | `build\build_x64.ps1` 的 `-PgVersion` 参数（默认 16.4-1） |
| 下载文件 SHA-256 | `build\vendor.lock.json`（`-UpdateLock` 生成） |
| 本清单 | `docs\依赖与许可证清单.md` |
